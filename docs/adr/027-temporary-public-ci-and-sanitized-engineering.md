# ADR-027: Temporary public CI and sanitized engineering

Date: 2026-11-02.
Status: **ACCEPTED / TEMPORARY / OWNER-APPROVED / GPT-5.6 SOL INDEPENDENTLY REVIEWED**.
Authority: owner-supplied latest macro brief and its fresh external independent disposition.

Requirements: R-025, R-032; ER-01, ER-09, ER-13, ER-14, ER-15.

## Context

Private hosted CI was billing-blocked; the owner supplied a fresh independently reviewed
macro disposition authorizing this temporary sanitized-public scope.

## Decision

Long-term intended repository visibility remains PRIVATE. The owner intentionally selected
temporary PUBLIC because private GitHub-hosted Actions were billing-blocked. PUBLIC is
currently authorized for free standard hosted CI and generic sanitized source, synthetic
fixtures, generic research framework, reviewed OI engineering, public provider documentation
references and generic/synthetic DS-03 engineering. Do not stop safe work solely for this
verified public state. No paid billing change, permission, runner, workflow or visibility
change is authorized by this ADR.

Public commits and copies cannot be retroactively revoked. Existing historical machine/user
metadata retention is explicitly owner-authorized exactly as it already existed. Publish
no NEW machine identifiers, real secrets, API keys/tokens, actual broker account identifiers,
private broker/session data, owner-private DB dumps, proprietary confidential alpha or
private financial policy. Local identities/receipts and real local OI secrets/data remain
ignored/local. Run source/history and high-signal scans before every public push. A detected
real credential requires PUBLIC_SECRET_EXPOSURE_RESPONSE_REQUIRED; do not print it or
rewrite history.

Actual broker account/session/credential onboarding requires verified PRIVATE return and
a separately accepted onboarding step. Confidential proprietary alpha/candidate/champion
work also requires PRIVATE return. Generic/synthetic DS-03 engineering does not require
an early private-return interruption. Later PRIVATE return does not erase prior public
copies. Visibility grants no financial authority, account access, order capability,
START acceptance or operational qualification.

## Supersession and retained gates

This decision supersedes prior present-tense PRIVATE assertions and expired temporary-public
return blockers only for the temporary sanitized scope above. Preserve dated historical
sections and prior frozen source/research decisions. It does not authorize permanent public
operation or change OI-FWD-v1, OI-16, rights, frozen files, protected operational schedules,
consumed OOS, phase exits or review/activation gates. Review this temporary disposition at
actual broker onboarding, confidential alpha work or a relevant rights/security change;
PRIVATE return remains a founder action, not an agent visibility mutation.

[Implementation acceptance](../reviews/PHASE_6A1_OI_IMPLEMENTATION_INDEPENDENT_ACCEPTANCE.md)
accepts exact b3e8 executable engineering only. PR #10 requires a docs-only child, actual
passing hosted CI and verified normal merge before runtime/DS-03 continuation. The future
DS-03 PR remains unmerged for independent exact-SHA review. PHASE6_FORWARD_CLOCK stays
ZERO until separate independently accepted owner START. No REAL account, money action,
Phase 5 order commissioning, runtime AI or Binance live derivatives authority is granted.

## Alternatives

Remain private with unavailable hosted CI: retains privacy but cannot supply actual hosted
executable results under the current free allocation. Permanent public operation is not
authorized. Paying for CI or changing runners/settings is outside this authority.

## Consequences

Public source and copies remain discoverable after any later private return. Source/history
scans and sanitized generic fixtures are mandatory; real broker onboarding stays blocked
until verified private return. Existing historical metadata stays as previously authorized.

## Validation

Verify authenticated PUBLIC visibility, exact accepted source lineage, actual CI executable
steps, docs-only administrative diff, aligned agent files, source/history/high-signal scans,
and normal merge parents/tree. Preserve frozen OI bytes and the operational release.

## Review point

Revisit before actual broker account/session/credential onboarding, confidential alpha work,
or a relevant rights/security change. The owner performs private return; no permanent-public
approval or expiry waiver beyond this scoped temporary disposition is inferred.
